# video

Use this skill as the single entry point for video work.

Start with the user's use case. Then load only the reference that matches it.

## Route by intent

Read `references/routing.md` first.

Use these references after routing:

- `references/hyperframes.md` for HyperFrames projects and renders.
- `references/gif.md` for README-ready demo GIFs.
- `references/media.md` for assets, audio, captions, and media treatments.
- `references/checklist.md` for final validation.

## Rules

- Do not choose a workflow from tool names alone.
- Match the requested deliverable.
- Ask for missing subject or source material before work starts.
- Keep the project CLI current before render-affecting commands.
- Preserve the existing project state when editing an existing video.
- Verify before rendering or shipping.
