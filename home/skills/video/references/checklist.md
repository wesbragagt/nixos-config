# Final checklist

Before delivery, verify the requested scope and the output.

## Always check

- The output matches the user's intended deliverable.
- The subject and source material are correct.
- The duration and format match the brief.
- Text is readable.
- Contrast is acceptable.
- No private data appears.
- Audio is present when required.
- Captions are present when required.

## HyperFrames

Run:

```bash
npx hyperframes check
```

Preview before render.

Render only after approval, unless the user explicitly asked for autonomous render.

## GIF

Inspect key frames and the final GIF.

Confirm the README link works.

## Final reply

Include:

- output path;
- actual duration when known;
- validation result;
- next action when approval is still needed.
