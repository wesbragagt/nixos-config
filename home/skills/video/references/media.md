# Media reference

Use this inside the active video route for media needs.

## Use cases

- background music
- sound effects
- voiceover
- captions and transcription
- images, icons, and logos
- footage cuts and reframes
- color grade and LUTs
- media treatments
- audio mixing and voiceover carve

## Rules

- Adopt existing local assets before sourcing new assets.
- Record media provenance when possible.
- Show authentication status before authenticated provider actions.
- Continue offline only when the required capability has an offline path.
- Do not store secrets in a project file.
- Do not replace a media treatment with a generic CSS filter when a real media treatment is needed.

## Audio

For narration, choose a voice from the user's request first.

If the user gives no voice preference, use the remembered voice when available.

If neither exists, use the workflow default.

For background music, match the mood and pacing of the video.

For voiceover plus music, ensure the music does not mask speech.
